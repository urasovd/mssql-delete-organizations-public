# Обработки 1С

XML-исходники внешних обработок. Сборка в `build\1c\*.epf`:

```powershell
.\scripts\Build-1CTools.ps1
```

Сборка идёт во временной файловой базе: ни серверная база, ни пользователь 1С
не нужны. Код компилируется при открытии обработки в целевой базе.

## Подготовка копии после выделения

`ПодготовкаКопииПослеВыделения` — для любой конфигурации на БСП. Методы модуля
объекта принимают и возвращают структуры из примитивных значений, поэтому их
вызывает и форма, и `scripts/50-volume-files.ps1` через `MCP_Toolkit`.

**Файлы на томах**

| Метод | Что делает |
|---|---|
| `СводкаФайловНаТомах()` | файлы в томах по справочникам и томам, способ хранения новых файлов |
| `ДоступСервераКТомам(ПодменаПутей)` | видит ли сервер 1С каталоги томов |
| `СохранитьУчетныеДанныеСервера(Сервер, Пользователь, Пароль)` | `cmdkey` для учётной записи сервера 1С (из серверного кода); пароль никуда не записывается |
| `ПроверитьФайлыНаТомах(Параметры)` | наличие и размер каждого файла, без чтения содержимого |
| `ЗагрузитьФайлыВБазу(Параметры)` | файл в базу, как `ПеренестиВБазу` БСП, но без удаления файла с тома и в режиме загрузки, без логики конфигурации; транзакция на файл |
| `ОтвязатьТома(ТолькоПроверка, ВключаяТомаСФайлами)` | новые файлы — в базе, пути томов очищены |

Справочники файлов — как в обработке БСП «Перенос файлов»: определяемый тип
`ПрисоединенныйФайл` и `ВерсииФайлов` вместо владельцев версий. Порции
ограничены числом файлов и объёмом; позиция в ответе передаётся в следующий
вызов.

**Проводки удаляемых документов** (переход на типовую конфигурацию)

| Метод | Что делает |
|---|---|
| `ВидыДокументовСДвижениями(Префиксы)` | виды документов с движениями по регистрам бухгалтерии и накопления; виды из расширений и с префиксами предлагаются к переносу |
| `ПроверитьПереносПроводок(Параметры)` | документы и движения к переносу, регистры, которые не переносятся |
| `ПеренестиПроводкиВОперации(Параметры)` | «Операция (бух)» с движениями документа, сверка количества и ресурсов (у регистра бухгалтерии — и колонок `…Дт`/`…Кт`), движения документа очищаются явно, документ помечается на удаление, проверка, что движений у него не осталось; транзакция на документ |

Регистры, которые исчезнут вместе с документами (например, `бит_*`), исключаются
префиксами.

Проверено 2026-10-28 на копии `bit_copy`, загруженной из `.dt` (база
потом удалена): 34 документа `ad_НачислениеПроцентовПоЗаймам`, 152 проводки
перенесены, ошибок нет; обороты `Хозрасчетный` по всем 341 паре счетов
совпали со снимком до переноса; у документов не осталось движений (и
субконто); операций стало на 34 больше. Две ошибки, найденные проверкой:
- сверка не находила ресурсы регистра бухгалтерии, выгружаемые колонками
  `…Дт`/`…Кт` — исправлено (`КолонкиРесурса`);
- отмена проведения при пометке на удаление не удаляет движения документа,
  если у него «Удаление движений: не удалять автоматически» — проводки
  задваивались (в исходной обработке `ВыделениеОрганизацииИзБазыБИТВБП` так
  же). Теперь движения очищаются явно и проверяются.
