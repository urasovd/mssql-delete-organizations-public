# БИТ на базе Бухгалтерии предприятия 3.0

Копия базы группы компаний: 65 организаций, SQL Server 2014, платформа 8.3.27.
Выделялась одна организация с арендным бизнесом.

| Что | Значение |
|---|---|
| `Справочник.Организации` | есть код |
| Регистры | бухгалтерии (`Хозрасчетный`, субконто в `_AccRgED*`), накопления, сведений; регистров расчёта нет |
| Объём | 58 млн строк, файл данных 114 ГБ, около 6 000 таблиц |
| Особые подсистемы | аренда БИТ (`бит_ар_*`), бюджетирование, маршруты согласования (`бит_ПользовательскиеУсловия`) |
| Расширения | несколько собственных расширений заказчика со своими справочниками и документами |

Пример настроек — [`example.settings.json`](example.settings.json), решения по
объектам — [DECISIONS.md](DECISIONS.md), цифры прогонов —
[разбор прогонов](../../docs/CASE-STUDY.md).

## Особенности

- **Пересчёт итогов.** ТиИ `-RecalcTotals` (11 с) стабильно пропускает
  `Хозрасчетный`, `бит_ОборотыПоБюджетам`, `РеализованныеТоварыКомитентов`:
  их итоги остаются с данными удалённых организаций, около 3 млн строк. Эти
  три регистра находит `49` и пересчитывает `47 -TotalsRegister`
  (`ПересчитатьИтоги()`, около 75 с). Причина пропуска не выяснена.
- **Обновление ИБ** ключом `/C ЗапуститьОбновлениеИнформационнойБазы`
  работает: 44 обработчика за 29 с, в фоне, без формы прогресса. Видно только в
  журнале регистрации.
- **Файлы на томах** (`\\<сервер>\<шара>\<год>\`): загружаются в базу стадией
  `Files`. Сервер 1С видит шару через учётку, сохранённую для его пользователя
  (только чтение). В хранилище нет части файлов, на которые ссылается база
  (2 из 13 565).
- **ТиИ и лицензия.** Если лицензия разработчика общая на сервер, открытый
  клиент другой базы может не дать конфигуратору стартовать (`46` сообщает
  `license_error`). Регламентные задания копии блокирует `46 -PrepareCluster`.
- **Исходные дефекты** (были до удаления, ТиИ находит их и в источнике):
  около 2 780 ссылок на отсутствующие ключи доступа, монитор руководителя и
  аналитику НДС. `44` отделяет их от находок, вызванных удалением.
- **Граница последовательности** есть только у
  `бит_ар_ВзаиморасчетыСАрендаторами`: восстанавливается перепроведением.
- **Сверка после закрытия месяцев.** Расходились только регламентные операции
  закрытия (десятки рублей в месяц). Причина — в источнике меняли график
  аренды после закрытия, удаление ни при чём.
- **Реквизит «Редактирует» у присоединённого файла** держит файл занятым и
  мешает удалению: такой файл освобождается адресно, одним полем, после
  проверки, что строка одна. Обнулять поле у всех файлов нельзя.
- **Объекты расширений** описаны только в `ConfigCAS`: без них каталог `40`
  не видит их справочники, и политики по логическому имени до них не
  доходят.
