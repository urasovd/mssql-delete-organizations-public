# Лицензия 1С и прямой доступ к базе

## Что говорит 1С

- Лицензионное соглашение запрещает вносить изменения в содержимое баз
  данных, кроме штатных средств, описанных в документации, и обращаться к
  информационной базе средствами, не предусмотренными документацией
  ([соглашение](https://1c.ru/texts/kp_license.htm)).
- В ответах по лицензированию 1С уточняет: средства СУБД допустимы, только
  если документация рекомендует их для конкретной задачи; обращение к данным в
  обход объектов платформы запрещено, и на чтение, и на изменение
  ([ответы по лицензированию](https://v8.1c.ru/priobretenie-i-vnedrenie/otvety-na-tipovye-voprosy-po-litsenzirovaniyu-1s-predpriyatiya-8/)).
- Базы, изменённые в обход платформы, лишаются поддержки фирмы 1С.

## Что в этом репозитории работает в обход платформы

| Скрипт | Что делает в SQL |
|---|---|
| `40`, `41`, `43`, `45`, `49` | читают таблицы и схему хранения |
| `42`, `11` | меняют и удаляют строки |
| `48` | обслуживание файлов и индексов SQL Server |

Через платформу (конфигуратор, `rac`, COM-соединение, обработка 1С) работают
`46`, `47`, `50`, `51`, `52` и обработка `1c/`.

## Как этим пользоваться

- Только на копии. Результат — новая база, исходная не меняется.
- Решение о применении результата и ответственность за него — на вас и
  владельце лицензии.
- Перед выдачей база проходит обновление ИБ, ТиИ и сверку с копией до
  удаления; без этих шагов результат не считается готовым.
