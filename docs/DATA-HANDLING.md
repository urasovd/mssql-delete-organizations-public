# Правила хранения результатов

В Git разрешены только технические схемы, скрипты, агрегированные отчёты и
контрольные суммы. Нельзя коммитить:

- пароли, токены, профили с секретами и полные строки подключения;
- наименования, ИНН и иные реквизиты организаций;
- полные строки документов, регистров или справочников;
- большой manifest с бинарными идентификаторами без отдельного согласования;
- резервные копии баз и журналы транзакций.

Построчные артефакты хранятся отдельно с ограничением доступа. Для каждой
итерации в репозитории фиксируются дата, сервер/база без секретов, версия
скриптов, агрегаты, контрольная сумма внешнего manifest и статус read-only или
DML.

Все будущие DML-скрипты должны требовать явного режима выполнения, проверять
целевую базу, наличие свежей копии и `preserve set`, а также писать пакетный
журнал и поддерживать повторный запуск.
